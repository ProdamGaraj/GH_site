## Полезный инструмент для вёрстки

Почти все проблемы мобильной версии — элементы шире экрана. Вставьте в консоль DevTools на нужной ширине, и он подсветит виновников:

```js
// Подсвечивает элементы, которые вылезают за правый край окна
[...document.querySelectorAll('body *')].forEach(el => {
  const r = el.getBoundingClientRect();
  if (r.width && r.right > document.documentElement.clientWidth + 1) {
    el.style.outline = '2px solid red';
    console.log(Math.round(r.right), el);
  }
});
```

Ширины для регресс-проверки: **360, 375, 390, 414, 768, 1024, 1280, 1440, 1920 px**.

# 🔴 Критично

## #01 Заявки не доходят до менеджеров

**Где:** все формы сайта: модалка «Получить консультацию», «Контакты», «Коммерция», формы на страницах ЖК.

**Проблема.** После «отправки» данные пишутся только в `localStorage` браузера посетителя (ключ `goldenHouseLeads`) и в `window.dataLayer`. В скриптах страницы нет ни одного `fetch`, XHR или `sendBeacon`. Google Tag Manager не подключён, а `tracker.js` `dataLayer` не читает. Посетитель видит «Заявка отправлена», а менеджер не получает ничего. Имя и телефон при этом лежат в `localStorage` открытым текстом.

**Как исправить.**

1. Завести на бэкенде эндпоинт для заявок, например `POST /api/leads` (имя условное). Он должен:
   - проверять имя и телефон на сервере, не полагаясь только на браузер;
   - передавать заявку в CRM (amoCRM, Bitrix24 или что используется в отделе продаж);
   - отвечать `201` с id заявки или `4xx/5xx` с текстом ошибки;
   - ограничивать частоту запросов с одного IP (rate limit) и отсекать ботов через скрытое поле-ловушку (honeypot);
   - при сбое CRM сохранять заявку в очередь или базу и слать уведомление ответственному (например, в Telegram), чтобы лид не пропал.
2. На фронте заменить функцию `sendLead` в `setupCrmForms` и обработчик формы модалки на реальную отправку:

```js
async function postLead(form, source) {
  const fields = Object.fromEntries(new FormData(form));
  const utm = Object.fromEntries(
    [...new URLSearchParams(location.search)].filter(([k]) => k.startsWith('utm_'))
  );
  const res = await fetch('/api/leads', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      ...fields,
      source,                                   // 'consult-modal', 'contact-page', 'complex-harizma'…
      page: location.pathname,
      lang: document.documentElement.lang,
      utm
    })
  });
  if (!res.ok) throw new Error('Lead failed: ' + res.status);
  return res.json();
}
```

3. Показывать «Заявка отправлена» только после успешного ответа, при ошибке — понятный текст и телефон для связи (см. код в #02).
4. Удалить запись в `localStorage` и очистить то, что уже накопилось у посетителей:

```js
try { localStorage.removeItem('goldenHouseLeads'); } catch (e) {}
```

5. Не класть имя и телефон в `dataLayer`: в аналитику передавать только факт отправки и тип формы (`trackEvent('lead_sent', { source })`).

**Как проверить:** отправить тестовую заявку с каждой формы и убедиться, что она появилась в CRM; отключить сеть в DevTools и убедиться, что пользователь видит ошибку, а не «Заявка отправлена».

## #02 Пустая форма «отправляется» без проверки

**Где:** «Контакты», «Коммерция», формы на страницах ЖК.

**Проблема.** `setupCrmForms` вешает на **каждую** кнопку внутри формы обработчик `click` с `preventDefault()` и сразу «отправляет». Браузерная валидация не запускается, событие `submit` не возникает (поэтому `tracker.js` эти отправки тоже не видит). Поля не помечены `required`, на «Контактах» телефон — `type="text"`, хотя плейсхолдер `+998 __ ___ __ __` намекает на маску. Пустая форма выдаёт «Заявка отправлена».

**Как исправить.**

1. Убрать обработчики `click` на кнопках. Слушать только `submit` и только у форм заявок: пометить их атрибутом, чтобы калькулятор и прочие формы не попадали под обработчик.

```html
<form class="lead-form" data-lead="complex-harizma" novalidate>
  <input type="text" name="name" required minlength="2" autocomplete="name" placeholder="Ваше имя">
  <input type="tel" name="phone" required autocomplete="tel" inputmode="tel"
         pattern="^\+998[\s-]?\d{2}[\s-]?\d{3}[\s-]?\d{2}[\s-]?\d{2}$"
         placeholder="+998 90 123-45-67">
  <!-- ловушка для ботов: люди это поле не видят и не заполняют -->
  <input type="text" name="website" tabindex="-1" autocomplete="off" hidden>
  <button type="submit">Получить консультацию</button>
  <p class="form-error" role="alert" hidden></p>
</form>
```

```js
document.querySelectorAll('form[data-lead]').forEach(form => {
  form.addEventListener('submit', async (e) => {
    e.preventDefault();
    if (!form.checkValidity()) { form.reportValidity(); return; }

    const btn = form.querySelector('[type=submit]');
    const err = form.querySelector('.form-error');
    const label = btn.textContent;
    btn.disabled = true;
    btn.textContent = 'Отправляем…';
    err.hidden = true;

    try {
      await postLead(form, form.dataset.lead);          // функция из #01
      btn.textContent = 'Заявка отправлена';
      form.reset();
      trackEvent('lead_sent', { source: form.dataset.lead });
    } catch (e) {
      btn.disabled = false;
      btn.textContent = label;
      err.textContent = 'Не удалось отправить заявку. Попробуйте ещё раз или позвоните +998 78 150-11-11.';
      err.hidden = false;
    }
  });
});
```

2. Добавить маску телефона. Простой вариант — библиотека IMask (`mask: '+{998} 00 000-00-00'`), либо свой обработчик `input`, который оставляет только цифры и расставляет пробелы.
3. Тексты ошибок валидации сделать по-русски и по-узбекски через `setCustomValidity()`, иначе браузер покажет системные сообщения.
4. Ту же проверку повторить на сервере (#01).

**Как проверить:** нажать «Отправить» с пустыми полями — форма не уходит и подсвечивает поля; ввести `123` в телефон — ошибка формата.

## #03 Калькулятор на «Покупателям» не считает

**Где:** https://test_analytics.gh.uz/ru/buyers/

**Проблема.** Стоимость 1 000 000 000 и взнос 300 000 000 → «Рассчитать» → кнопка на 2,4 с меняется на «Заявка отправлена», расчёта нет, в `localStorage` появляется пустой лид. У полей нет `name`, кнопка попадает под общий обработчик форм. Кнопка «Получить консультацию» ниже лежит в пустой форме и по коду тоже сразу пишет «Заявка отправлена».

**Как исправить.**

1. Убрать у калькулятора тег `<form>` или не помечать его `data-lead` (после исправления #02 он перестанет считаться заявкой).
2. Добавить поля срока и программы (ипотека или рассрочка) и сделать расчёт:

```html
<div class="calc" id="calc">
  <label>Стоимость квартиры, сум <input id="calc-price" inputmode="numeric" autocomplete="off"></label>
  <label>Первоначальный взнос, сум <input id="calc-down" inputmode="numeric" autocomplete="off"></label>
  <label>Срок
    <select id="calc-term"><option value="12">12 мес.</option><option value="24">24 мес.</option><!-- … --></select>
  </label>
  <label>Программа
    <select id="calc-program"><!-- заполняется из PROGRAMS --></select>
  </label>
  <button type="button" id="calc-run">Рассчитать</button>
  <output id="calc-result" aria-live="polite"></output>
</div>
```

```js
// Ставки, сроки и минимальный взнос — взять у банков-партнёров и отдела продаж.
// Здесь только структура, цифры не придумывать.
const PROGRAMS = {
  installment: { name: 'Рассрочка Golden House', rate: 0,    maxMonths: 24,  minDownPct: null },
  orient:      { name: 'Ипотека Orient Finans Bank', rate: null, maxMonths: null, minDownPct: null },
  trust:       { name: 'Ипотека Trustbank',          rate: null, maxMonths: null, minDownPct: null }
};

const fmt = new Intl.NumberFormat('ru-RU');
const num = (el) => Number(el.value.replace(/\D/g, '')) || 0;

// Разбивка разрядов прямо при вводе: 1 000 000 000
['calc-price', 'calc-down'].forEach(id => {
  const el = document.getElementById(id);
  el.addEventListener('input', () => { const v = num(el); el.value = v ? fmt.format(v) : ''; });
});

function monthlyPayment(principal, months, yearRatePct) {
  if (!yearRatePct) return principal / months;              // рассрочка без процентов
  const r = yearRatePct / 100 / 12;
  return principal * r / (1 - Math.pow(1 + r, -months));    // аннуитетный платёж
}

document.getElementById('calc-run').addEventListener('click', () => {
  const price = num(document.getElementById('calc-price'));
  const down = num(document.getElementById('calc-down'));
  const months = Number(document.getElementById('calc-term').value);
  const p = PROGRAMS[document.getElementById('calc-program').value];
  const out = document.getElementById('calc-result');

  if (!price || down >= price) { out.textContent = 'Проверьте стоимость и взнос: взнос должен быть меньше стоимости.'; return; }
  if (p.minDownPct && down < price * p.minDownPct / 100) {
    out.textContent = `Минимальный взнос по программе — ${p.minDownPct}% (${fmt.format(Math.ceil(price * p.minDownPct / 100))} сум).`;
    return;
  }
  const pay = Math.round(monthlyPayment(price - down, months, p.rate));
  out.textContent = `Ежемесячный платёж: ${fmt.format(pay)} сум на ${months} мес. Расчёт предварительный, точные условия уточняйте у менеджера.`;
  trackEvent('calc_used', { program: document.getElementById('calc-program').value, months });
});
```

3. Под результатом поставить кнопку «Получить точный расчёт», которая открывает модалку консультации (см. #04) с уже заполненными суммами в скрытых полях.
4. Кнопку «Получить консультацию» в блоке «Контакты сервиса» вынести из пустой `<form>` и повесить на неё `data-consult-trigger`.

**Как проверить:** 1 000 000 000 / 300 000 000 / 12 мес. / рассрочка → 58 333 333 сум в месяц.

## #04 Кнопка «Записаться на просмотр» ничего не делает

**Где:** главная, карточка «25 000+ семей с нами» в первом экране.

**Проблема.** Модалка консультации открывается только элементами с атрибутом `data-consult-trigger`, а таких на сайте нет. Кнопка `button.gbook` в первом экране не привязана ни к чему. Форму можно открыть только из всплывающего промо-окна.

**Как исправить.**

1. Добавить атрибут на кнопку в шаблоне:

```html
<button type="button" class="gbook" data-consult-trigger data-consult-source="hero-viewing">
  Записаться на просмотр <span class="arw" aria-hidden="true">↗</span>
</button>
```

2. Не привязываться к классу `.gbook`: скрипт уже переделывает `.nav-actions > .gbook` в ссылку на телефон, общий селектор зацепит лишнее.
3. В `openConsultModal` принимать источник и заголовок, чтобы в CRM было видно, откуда заявка:

```js
document.querySelectorAll('[data-consult-trigger]').forEach(btn => {
  btn.addEventListener('click', () => openConsultModal({
    source: btn.dataset.consultSource || 'unknown',
    title: btn.dataset.consultTitle   // например, «Записаться на просмотр»
  }));
});
```

4. Пройтись по всем CTA сайта («Получить консультацию» на «Покупателям», «Подробнее» в «Коммерции», кнопки на страницах ЖК) и проставить атрибут там, где должна открываться форма.

**Как проверить:** на главной, «Покупателям» и в «Коммерции» каждая кнопка записи или консультации открывает модалку.

## #06 Бургер-меню: «Контакты» открывают 404

**Где:** все страницы на экранах до 1024 px (телефоны, планшеты, небольшие ноутбуки). На 1280 px и шире показывается верхнее меню, в нём ссылки верные.

**Проблема.** В `.gnav-drawer-menu`:
- «Контакты» → `/ru/contacts` → **404** (правильно `/ru/contact/`);
- «Коммерция» → старая `/ru/commerce` вместо `/ru/commercev2/` (см. #13).

**Как исправить.**

1. Исправить ссылки в шаблоне бургер-меню на обоих языках.
2. Собирать верхнее меню и бургер из одного списка, чтобы они больше не расходились:

```js
const NAV = [
```

## #34 Логотип теряется на тёмном фоне

**Где:** все страницы при прокрутке над тёмными блоками («Подборка всех проектов», подвал, «Коммерция»).

**Проблема.** Тёмный логотип в полупрозрачной шапке почти не виден.

**Как исправить.** В коде уже есть `syncLogoContrast()` и классы `.glogo-light` / `.glogo-dark`, но переключение не срабатывает над тёмными секциями. Пометить тёмные секции и переключать логотип по секции, которая находится под шапкой:

```html
<section class="complexes-feature" data-header-theme="dark">…</section>
<footer id="site-footer" data-header-theme="dark">…</footer>
```

```js
const nav = document.querySelector('.gnav');
const headerH = 80;
const io = new IntersectionObserver(entries => {
  entries.forEach(e => {
    if (e.isIntersecting) {
      const dark = e.target.dataset.headerTheme === 'dark';
      nav.classList.toggle('logo-light', dark);
      nav.classList.toggle('logo-dark', !dark);
    }
  });
}, { rootMargin: `0px 0px -${innerHeight - headerH}px 0px` });   // срабатывает на полосе под шапкой
document.querySelectorAll('section, footer').forEach(s => io.observe(s));
```

Секциям без `data-header-theme` по умолчанию светлая тема. Альтернатива — сделать подложку шапки плотнее (`background: rgb(255 255 255 / .85)`), тогда тёмный логотип читается всегда.

## #45 Аналитика и загрузка ресурсов

**Проблема.**
- `trackEvent` пишет `page: "index.html"` на всех страницах (берёт последний сегмент пути, а у `/ru/` он пустой); у лида поле `page` — заголовок вкладки («golden-house-single»).
- Отправки форм на «Контактах», «Коммерции» и ЖК не видит `tracker.js`: он слушает `submit`, а текущий код его гасит (#02).
- Google Fonts Inter подключён дважды.
- В CSS объявлен шрифт Muller, файлы `/fonts/Muller-*.woff2` отдают 404, сам шрифт нигде не используется.
- Логотип в шапке грузится шириной 1024 px для показа в 118 px: у `<img>` стоит `sizes="(max-width: 1113px) 100vw, 1113px"`. Логотип в подвале — 1512 px для 178 px.
- Картинки ниже первого экрана без `loading="lazy"`.

**Как исправить.**

```js
function trackEvent(eventName, payload = {}) {
  window.dataLayer = window.dataLayer || [];
  window.dataLayer.push({ event: eventName, page: location.pathname, lang: document.documentElement.lang, ...payload });
}
```

```html
<!-- Логотип: браузер выберет маленький файл -->
<img class="glogo-dark" src="/media/…w430.webp" srcset="…" sizes="120px" width="118" height="42" alt="" aria-hidden="true">

<!-- Картинки ниже первого экрана -->
<img src="…" alt="…" loading="lazy" decoding="async" width="…" height="…">
```

- Удалить второй `<link>` на Google Fonts.
- Удалить `@font-face` для Muller или загрузить файлы шрифта, если он нужен.
- Логотипу лучше отдать SVG: он лёгкий и чёткий на любой плотности экрана.

### Скрипт проверки всех ссылок страницы

Запустить в консоли на любой странице сайта:

```js
(async () => {
  const urls = [...new Set([...document.querySelectorAll('a[href]')]
    .map(a => a.getAttribute('href'))
    .filter(h => h && !/^(#|tel:|mailto:|javascript:)/.test(h))
    .map(h => new URL(h, location.href).href)
    .filter(u => u.startsWith(location.origin)))];
  for (const u of urls) {
    const r = await fetch(u, { method: 'HEAD' });
    if (r.status >= 400) console.warn(r.status, u);
  }
  console.log('Проверено ссылок:', urls.length);
})();
```
